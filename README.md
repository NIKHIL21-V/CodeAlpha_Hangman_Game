# 🎮 Hangman Game in Python

## 📌 Project Overview
This project is a console-based Hangman Game developed using Python.
The player attempts to guess a randomly selected hidden word by entering
one letter at a time.

The game ends when the player guesses the complete word or reaches
the maximum number of incorrect guesses.

## ✨ Features
- Random word selection
- Interactive command-line gameplay
- Letter-by-letter word guessing
- Input validation
- Duplicate guess detection
- Six incorrect guesses allowed
- Win and game-over conditions

## 🛠️ Technologies Used
- Python 3
- Random module
- VS Code

## ▶️ How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run the following command:

   python hangman.py

## 🎯 Objective
To demonstrate Python programming fundamentals, including loops,
conditional statements, lists, user input, and random selection.
